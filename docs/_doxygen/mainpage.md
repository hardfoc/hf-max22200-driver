# MAX22200 Driver API reference {#mainpage}

The classes, members and types of the HardFOC MAX22200 driver, generated from the headers.

Start with max22200::MAX22200, the driver, and max22200::SpiInterface, the interface your platform port
implements. Channel settings are max22200::ChannelConfig, the STATUS register is max22200::StatusConfig, per-channel
faults are max22200::FaultStatus and the full-scale current is max22200::BoardConfig. Register addresses and bit
fields are in max22200_registers.hpp.

The guides, with examples that compile, are on the documentation site: <a href="../">MAX22200 Driver
documentation</a>.
